Cecile Yang Portfolio (offline copy)

1. Keep the folder together: index.html and the assets folder must stay side by side.
2. Double-click index.html to open it in Chrome, Edge or Safari.
3. Fonts load from Google Fonts. Open the site once while online, so the browser keeps the fonts. Without them the site still works, but the script and body fonts fall back to system fonts.
4. On the Work page, press the Right / Left arrow keys to jump to the next / previous project.
5. The videos on the COOKIT and Red pages play only when you press play.
